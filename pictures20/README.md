# pictures20 —— 现场测评样本目录（Web 测评页 /eval 的默认取图目录）

把**现场演示用的 20 张实拍图**放这里（或逐张改 `config/configs.yaml` 的 `EVAL.sample_dir`
指向你实际存放比赛图的目录）。

- 支持 jpg / jpeg / png / bmp / webp / jfif / tif；
- 文件按名称排序取前 20 张（超过 20 张只测前 20 张，少于 20 张按实际数量计分）；
- 页面打开 `http://<IP>:8080/eval` 后会自动「从服务器载入」，点「开始测评」即开始计时；
- 不想用服务器目录也可以：页面上直接「选择文件夹 / 选择图片」（不依赖本目录）。

> 目录里现在的 4 张 `Demo sample` 占位图仅用于页面自测演示（无真实害虫，检测结果会是
> 无目标）——正式演示前请替换成现场那 20 张照片。本目录不入 git（见 .gitignore）。
