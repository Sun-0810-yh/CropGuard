# edge_models —— EdgeJev 本地决策模型（构建产物目录）

本目录存放 EdgeJev 模型的构建产物（**不入 git**，每台机器本地构建或拷贝）：

| 目录 | 说明 | 体积 |
| --- | --- | --- |
| `jev-int8/` | **当前部署**：laya 后端（mmBERT-base 322M），INT8 动态量化 | ~335MB |
| `jev-mixed/` | 备用：决策路径保持 fp32 的混合量化（行为与 int8 接近） | ~369MB |

```
model.onnx      # 量化后的 ONNX 图
tokenizer.json  # 分词器
edgejev.json    # 后端/精度/温度/特殊 token 等配置（Agent 由此识别）
```

构建：`python scripts/build_edge_model.py`（见 [docs/edgejev.md](../docs/edgejev.md)）。
运行时只需要 `onnxruntime + tokenizers + numpy`，不需要 torch。

## 实测校准记录（2026-10-16，本机 CPU，用于 app/edge_engine.py 的阈值）

> 结论先行：**laya-multilingual 对自定义任务属零样本，规则必须优先；模型只在
> 「规则失败 + 高置信」时做指令兜底**。以下是定阈值用的原始记录（复现脚本见
> `scripts/edge_probes/`）。

### 1) 问法对照（同一批 13 条中文指令）

| 问法 | intent 准确率 | group 准确率 |
| --- | --- | --- |
| 中文长描述（"开始、执行或继续喷洒…"） | 差（"给片区A喷3秒"都被判成 stop） | 一般 |
| 中文动词短语（"喷洒杀虫/停止设备"） | 10/13 | 5/8 |
| **英文动词短语（当前采用）** | 11/13 | **8/8（单词）/ 12/13（合批）** |

→ 采用英文 instructions + 动词短语 criteria（在 `app/edge_engine.py` 的 `COMMAND_QUESTIONS`）。

### 2) 批次构成会改变答案（INT8 动态量化的已知特性）

| 同一输入 | 单题跑 | 4 题合批（线上口径） |
| --- | --- | --- |
| 把A区的水阀开一小会儿 | spray 0.65 | stop 0.76 |
| 蚜虫怎么防治 | stop 0.83 | other 0.50 |

→ 线上固定用同一套 4 题（顺序不变），保证**同问同答**；阈值按合批口径校准。

### 3) 模型变体对照（含构建正确性验证）

| 变体 | 体积 | 单题 intent | 合批 intent | 合批 group |
| --- | --- | --- | --- | --- |
| int8（部署） | 335MB | 9/13 | 8/13 | **12/13** |
| fp32 | 1290MB | 8/13 | 8/13 | 9/13 |
| mixed | 369MB | 8/13 | 8/13 | 12/13 |
| kev-fp32（Qwen2.5-0.5B） | ~4GB | **10/13** | 10/13 | 7/13 |

注意：fp32 并不比 int8 准（量化噪声在这个任务上甚至更"稳"），且大 4 倍；kev 意图略好但片区差、
体积爆炸。**构建正确性另证**：官方 README 旗舰示例（工单 → dept）在 int8 上命中
`billing` 概率 0.91–0.99，与官方宣称一致 → 构建管线本身没问题，弱的是零样本能力。

### 4) 停止类兜底阈值（RESCUE_STOP_MIN=0.85 的来历）

| 输入 | 期望 | stop 概率（合批） |
| --- | --- | --- |
| 把泵关了吧 | 停止 | 0.934 |
| 把水停了 | 停止 | 0.964 |
| 给B区关一下 | 停止 | 0.974 |
| 别让它喷了 | 停止 | 0.983 |
| —— | —— | —— |
| 把A区的水阀开一小会儿 | 喷洒 | 0.756 ✗ |
| B区再来两秒吧，刚才不够 | 喷洒 | 0.606 ✗ |
| 把A区的水打开 | 喷洒 | 0.628 ✗ |

真停止 ≥0.93、假停止 ≤0.76 → 阈值取 **0.85**，落在空档里；同时真喷洒指令的
stop 概率 ≤0.33，不会被误伤。

### 5) 顺带修复的规则侧问题（llm/ai_gateway.py）

"把泵关了吧 / 给B区关一下 / A区的雾化关掉" 这类说法原来会被规则漏判甚至**误判成喷洒**，
已扩充停止词表（关闭/关掉/关了/关一下…）、并把**危险词检查挪到最前**（防止
"关闭安全限制"被当成停止指令）；停止时也会读片区（"A区关掉"只停 A 区）。
