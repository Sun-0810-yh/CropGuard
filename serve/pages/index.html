API 接口

除了本页面，您也可以直接调用 REST API:

打开现场测评页 /eval（20 样本 / 180 秒，动效计时 + 评委判分 + 报告导出，与 GUI 同口径）

打开 EdgeJev 推理入口 /edge（本地类型化决策：指令解析对照 / 虫情研判 / 通用 systemone）

打开移动端实时监测页 /stream（实时画面 + 喷淋联动）

POST /api/detect - 上传图片检测 (multipart/form-data, field: file)

POST /api/detect_b64 - Base64图片检测 (JSON: {"image": "base64..."})

POST /api/spray - 手动喷淋 (JSON: {"group":"all","duration":2})

GET /api/edge/status · POST /api/edge/systemone · /api/edge/parse_command · /api/edge/advise - EdgeJev 本地类型化决策

GET /api/eval/config · POST /api/eval/score · POST /api/eval/report - 现场测评口径与报告

GET /api/history - 联动/喷淋历史

WS /ws/stream - 摄像头实时流

GET /api/health - 健康检查

GET /api/info - 模型信息
